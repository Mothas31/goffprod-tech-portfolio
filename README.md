## 👋 À propos

Je suis développeur freelance, avec un fort intérêt pour :
- la **performance**
- la **sobriété logicielle**
- la **clarté des systèmes complexes**
- la **pédagogie technique**

Mon travail consiste autant à **concevoir et refactorer** des applications qu’à

(décideurs, PME, équipes sans référent technique fort).

---

## 🎯 Ce que je construis ici

Ce dépôt contient mon **portfolio technique**.

Ce n’est pas un CV, ni une simple vitrine graphique, mais :
- une démonstration de **raisonnement**
- un espace d’**expérimentation maîtrisée**
- une preuve de **choix techniques assumés**

Le portfolio est volontairement construit :
- sans framework full-stack
- avec un JS minimal
- en intégrant **Rust & WebAssembly** pour les parties logiques et interactives

👉 Le but n’est pas d’impressionner par la complexité,  
mais de convaincre par la cohérence.

---

## 🧠 Principes directeurs

- Choisir une technologie **pour une raison**, pas par habitude
- Préférer la **lisibilité** à l’abstraction inutile
- Considérer la performance et l’éco-conception comme des **contraintes de base**
- Toujours penser en termes de **système**, pas seulement de code
