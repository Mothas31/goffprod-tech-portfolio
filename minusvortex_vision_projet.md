# MinusVortex — Vision, Positionnement et Intention

## Pourquoi ce projet existe

MinusVortex n’est pas un simple portfolio de développeur.

Ce n’est pas un site pour dire :

> "Je fais du Laravel, contactez-moi."

Le projet existe pour porter une vision plus large :

# Faire moins, mais mieux.

Moins de bruit.
Moins de dette.
Moins de dépendance.
Moins de complexité inutile.

Plus de clarté.
Plus de maîtrise.
Plus d’ownership.
Plus de solidité.

La technique n’est pas une fin.
Elle doit servir le réel.
Le business.
Le temps humain.
La qualité de vie.

Un mauvais système vole du temps.
Un bon système rend de la liberté.

---

# Le centre de gravité

Le projet ne tourne pas autour de "Thomas".

Le centre est :

# Ownership + Sobriété + Performance

Tout le reste doit revenir à cela.

Même si le site parle de :

- développement
- santé
- discipline
- organisation
- philosophie
- performance
- écoconception
- travail
- structure personnelle

… tout doit rester connecté à cette idée centrale.

Sinon le site devient confus.

---

# Ce que MinusVortex vend réellement

Pas :

> du développement web

Mais :

# de la réduction de chaos

Exemples :

- réduire la dette technique
- simplifier des systèmes trop lourds
- optimiser la performance
- améliorer la stabilité
- réduire les coûts invisibles
- améliorer l’architecture
- rendre un projet durable
- remettre de la clarté dans l’organisation

Le client ne paie pas pour du code.
Il paie pour :

- moins de risques
- moins de perte de temps
- moins de dépendance
- plus de contrôle

Le code n’est qu’un outil.

# Positionnement professionnel

## Garder les ERP

Les ERP et projets legacy restent utiles.

Ils financent la guerre.

Mais ils ne doivent pas définir l’identité.

Les projets chiants doivent être mieux facturés.

Le chaos a un prix.

Exemples :

- urgence
- legacy instable
- forte responsabilité
- flou client
- dette historique
- interventions critiques

=> surcharge tarifaire assumée

Le but n’est pas de fuir ces projets.
Le but est de ne plus les subir gratuitement.

# Le questionnaire d’alignement

Le questionnaire n’est pas un gadget.

C’est un filtre stratégique.

Objectif :

## savoir si la collaboration a du sens

Exemples de questions :

- cherchez-vous un exécutant ou un partenaire ?
- préférez-vous vitesse immédiate ou robustesse durable ?
- voulez-vous impressionner ou durer ?
- cherchez-vous plus de contrôle ou plus de délégation ?
- acceptez-vous de simplifier plutôt que d’ajouter ?

Le but n’est pas de convaincre tout le monde.

Le but est de laisser partir les mauvais clients.

Et d’attirer les bons.
